# Notes for Claude

- Recipes are XML following `zz-TEMPLATE.xml`; see README.md for the schema.
- Each XML file starts with `<?xml-stylesheet type="text/css" href="zz-recipe-style.css"?>`; keep that line, and keep a copy of `zz-recipe-style.css` in every category folder.
- Escape `&` as `&amp;` in XML.
- Quantities use NZ conventions (C = cup, Tbs = tablespoon, tsp = teaspoon, temperatures in deg C).
