# Notes for Claude

- Recipes are XML following `zz-TEMPLATE.xml`; see README.md for the schema.
- Each recipe XML file (in a category folder) starts with `<?xml-stylesheet type="text/css" href="../zz-recipe-style.css"?>`, pointing at the single stylesheet in the root folder; keep that line. Do not put copies of the stylesheet in the category folders.
- Escape `&` as `&amp;` in XML.
- Quantities use NZ conventions (C = cup, Tbs = tablespoon, tsp = teaspoon, temperatures in deg C).
